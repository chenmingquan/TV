4. ⚠️ 系统默认 JDK 是 1.7，必须显式切换到 `D:\workSofts\jdk\jdk21`
5. ⚠️ 目录不是 git 仓库（无 `.git`），建议先建立基线提交

> 第 3 项是唯一需要外部获取文件的硬阻塞，其余均可本地生成。
