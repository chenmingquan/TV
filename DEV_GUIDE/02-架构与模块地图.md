# 02 · 架构与模块地图

> 面向后续 AI 二次开发的代码地图。所有路径以仓库根 `TV-fongmi/` 为基准。
> 包名统一为 `com.fongmi.android.tv`（主模块）与各子模块自有命名空间。

---

## 1. 工程物理结构

```
TV-fongmi/
├── app/                     主模块（唯一 application 模块）
│   ├── build.gradle         产品风味 leanback/mobile、签名、ABI 分包
│   ├── libs/                本地 AAR（fileTree 全量引入）
│   ├── schemas/             Room 导出 schema（当前 35.json）
│   ├── proguard-rules.pro
│   ├── proguard-rules-media.pro
│   └── src/
│       ├── main/            共用逻辑（跨端，24 个包）
│       ├── leanback/        电视版 UI（遥控器交互）
│       └── mobile/         手机版 UI（触控交互）
├── catvod/                  CatVod Spider 协议 + 网络/工具基础（library）
├── chaquo/                  Chaquopy Python 3.10 运行时（library）
├── quickjs/                 QuickJS JavaScript 运行时（library）
├── forcetech/ jianpian/ thunder/ tvbus/ zlive/ hook/
│                            ⚠️ 未纳入 settings.gradle，不参与构建
│                            其 release AAR 已放入 app/libs/ 被引用
├── buildSrc/                自定义构建插件（Groovy）
│   └── src/main/groovy/com/fongmi/gradle/
│       ├── AbiApkPackaging.groovy   ABI 分包 + 输出改名
│       └── FinalizeApksTask.groovy  zipalign + apksigner 签名
├── website/                 官方文档静态站（Next.js，独立构建）
├── gradle/libs.versions.toml  版本目录（唯一依赖版本来源）
└── settings.gradle          只 include：app / catvod / chaquo / quickjs
```

**关键约束：`settings.gradle` 只包含 4 个模块。** `forcetech / jianpian / thunder / tvbus / zlive / hook` 虽有源码目录，但不参与 Gradle 构建，运行时靠 `app/libs/*-release.aar` 提供。修改这些模块的 Java 源码不会生效，必须先构建出 AAR 再替换 `app/libs` 中的文件。

## 2. 三源集（sourceSets）分工

| 源集 | 定位 | 主要包 |
| --- | --- | --- |
| `app/src/main` | 全部共用业务逻辑：配置解析、Spider 加载、播放引擎、数据层、本地服务、设置 | `api/ bean/ db/ player/ playback/ server/ setting/ model/ impl/ utils/ …` |
| `app/src/leanback` | 电视版 UI（遥控器焦点体系） | `ui/activity/ ui/fragment/ ui/adapter/ ui/presenter/ ui/custom/ ui/dialog/ ui/holder/` + `dlna/ service/ receiver/` |
| `app/src/mobile` | 手机版 UI（触控手势、扫码、生物识别） | 同上结构 + 独有 `FolderActivity / HistoryActivity / ScanActivity` |

- 三个源集 **包名完全相同**，同名类在不同源集实现不同（Leanback 的 `HomeActivity` vs Mobile 的 `HomeActivity`）。
- 统计：`app/src` 共 **463 个 .java**；`res/layout` 共 **192 个**布局。
- main 包文件数：`player` 57、`ui` 38、`bean` 38、`utils` 21、`playback` 20、`impl` 17、`api` 16、`db` 11、`server` 10、`setting` 10、`model` 5、`event` 6、`gson` 7、`dlna` 3、`browse` 3。

## 5. 核心数据流

```
配置(URL/JSON) → VodConfig/LiveConfig 解析
     ↓
sites[]/lives[] → SiteApi/LiveApi
     ↓
BaseLoader 按 type 分派：
     type 0/1 → HTTP (XML/JSON)
     type 3   → Spider: JarLoader(Java csp_Xxx) / PyLoader(*.py) / JsLoader(*.js, QuickJS)
     type 4   → HTTP 扩展 JSON
     ↓
Spider 方法 → Result（bean/Result.java，22 字段）
     ↓
SiteViewModel / LiveViewModel（model/）
     ↓
leanback|mobile UI（RecyclerView / Leanback Presenter）
     ↓
点击播放 → PlayerManager → PlayerEngineFactory 选引擎
     ↓
ExoPlayerEngine | MpvPlayerEngine → playback/ 会话编排 → PlaybackService
```

播放链路补充：`ParseJob` 负责解析（WebView / JSON / JAR），`Source` 表示播放源，`TrackUtil` 处理音轨/字幕轨，`PlayerEffectManager` 管理画面/音效滤镜（含 AV1/VP9 软解、libass 字幕、均衡器、限幅、响度归一化等）。

## 6. 数据层（Room）

`AppDatabase` 实体 7 张表：`Keep`（收藏）、`Site`（站点）、`Live`（直播源）、`Track`（播放进度轨）、`Config`（配置）、`Device`（设备）、`History`（观看记录）。

- Schema 导出目录 `app/schemas/`，当前版本 **35**（`Migrations` 管理升级）。
- 若二次开发新增表（如儿童管控规则表），**必须**：新增 Entity → 加入 `entities = {}` → 版本号 +1 → 写 Migration → 重新导出 schema。

---

## 7. 本地 HTTP 服务（`server` 包）

NanoHTTPD 实现，端口 **9978 → 9998 自动探测**。端点：`/action`（do=control/refresh/push/file/search/setting/cast/sync/danmaku）、`/media`、`/device`、`/file/{path}`、`/upload`、`/newFolder`、`/delFolder`、`/delFile`、`/cache`、`/proxy`、`/parse`、`/image/{key}`、`/tvbus`、`/`（内置控制页）。

> 无鉴权，仅限可信局域网。二次开发若新增端点，加入 `server/` 并在 `Server`/`Action` 中路由。

---

## 8. 构建与签名流程（`buildSrc`）

`AbiApkPackaging.configure()` 在 release 变体上：

1. `splits.abi` 启用，输出 `arm64-v8a` 与 `armeabi-v7a` 两个包（`universalApk = false`）
2. 输出改名：`{device}-{abi}.apk`（如 `leanback-arm64_v8a.apk`）
3. `FinalizeApksTask` 调用 `build-tools/<version>/zipalign.exe` + `lib/apksigner.jar` 完成对齐与签名
4. 产物导出到仓库根 `Release/apk/`（该目录被 .gitignore 忽略）

构建命令（PowerShell，仓库根）：

```powershell
.\gradlew.bat :app:assembleLeanbackRelease   # 电视版
.\gradlew.bat :app:assembleMobileRelease     # 手机版
```

## 10. 代码约定（必须遵守）

1. **Java 21**，`coreLibraryDesugaring` 已启用；启用 **ViewBinding**（`viewBinding = true`），不要手写 `findViewById`。
2. **EventBus** 已配置注解处理器并生成 `com.fongmi.android.tv.event.EventIndex`；新增事件类放 `event/`，不要改动索引配置。
3. **Room** 注解处理器已配置 `room.schemaLocation`；改数据库必须留 migration。
4. **依赖版本统一在 `gradle/libs.versions.toml`**，不要在 `build.gradle` 写死版本号。
5. **不要提交签名档与 `local.properties`**（.gitignore 已忽略 `*.properties`、`*.jks`、`lib-*.aar`）。
6. 资源与文案：现有 `values` / `values-zh-rCN` / `values-zh-rTW`，新增文案建议三处同步。
7. 端侧差异用 `leanbackImplementation` / `mobileImplementation` 引入依赖（如 leanback 的 AndroidAutoSize、mobile 的 Biometric/ZXing）。
