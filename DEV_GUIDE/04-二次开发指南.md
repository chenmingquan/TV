## 0. 开工前必做

1. **建立版本基线**：当前目录**不是 git 仓库**（无 `.git`）。开工前 `git init` + 首次提交，否则改坏无法回滚。
2. **固定 JDK 21**：`D:\workSofts\jdk\jdk21`（系统默认 java 是 1.7，会直接构建失败）。
3. **确认阻塞项已解除**：`local.properties`、keystore、`app/libs/lib-*.aar`（见 `01` 第 4 节）。
4. **先跑通一次基线构建**（`:app:assembleLeanbackDebug`），再开始改代码。

## 1. 现有代码模式速查（照抄，不要自创）

### 1.1 设置项持久化 —— `Prefers` + 静态 getter/putter

参考 `setting/Setting.java`：

```java
public static boolean isIncognito() {
    return Prefers.getBoolean("incognito");
}

public static void putIncognito(boolean incognito) {
    Prefers.put("incognito", incognito);
}
```

新增开关（如儿童模式）照此写，放 `setting/` 包。有取值范围时照抄 `Math.clamp(..., MIN, MAX)` 的写法。

### 1.2 数据库 —— Room

7 张表：`Keep` `Site` `Live` `Track` `Config` `Device` `History`（`db/AppDatabase.java`，schema v35）。
新增表必须同步：Entity → `entities={}` → 版本号 +1 → `Migrations` 写升级 → 导出 schema。

### 1.3 事件通信 —— EventBus

已配置注解处理器生成 `com.fongmi.android.tv.event.EventIndex`。新事件放 `event/` 包，用 `@Subscribe` 接收，不要动索引配置。

### 1.4 UI —— ViewBinding + 两端各一份

- `buildFeatures { viewBinding = true }`，用生成的 Binding 类，禁止 `findViewById`。
- 电视端页面放 `app/src/leanback/`，手机端放 `app/src/mobile/`，包名与类名可同名。
- **两端都加的页面，必须在各自 `AndroidManifest.xml` 注册**（main 的 Manifest 不注册端侧页面）。
- leanback 端改布局必须保持**遥控器焦点链**（`nextFocusUp/Down/Left/Right`、首个可聚焦项），否则遥控器无法操作。

### 1.5 依赖

一律在 `gradle/libs.versions.toml` 加版本与坐标，`build.gradle` 用 `libs.xxx` 引用。端侧专属依赖用 `leanbackImplementation` / `mobileImplementation`。

## 2. 功能一：儿童观看时间管控

**目标**：限制儿童每日/单次可观看时长、可观看时段，超时锁定（需家长密码解锁）。

### 建议落点

| 层 | 改动 |
| --- | --- |
| 配置存储 | 新建 `setting/KidSetting.java`：`isKidMode()`、`getDailyLimitMin()`、`getBedTime()`（`Prefers` 静态读写，照抄 `Setting` 模式） |
| 计时持久化 | `db` 新增 `KidUsage` 表（日期、已用分钟、最后更新时间），或复用 `Track`/`History` 推算。**推荐新表**，避免污染播放记录 |
| 拦截核心 | 新建 `main/java/.../kid/KidGuard.java`（两端共用的单例）：`checkAllow()`、`tick()`（播放中累计）、`lock()` |
| 计时驱动 | 在 `playback/VodPlaybackController`（或 `PlayerManager` 的播放状态回调）里 `tick()`；用 `Constant`/定时器上报 |
| 锁定 UI | 新建 `KidLockDialog`（放 `main/ui/dialog/`，两端复用）；家长解锁复用现有 `PassDialog` |
| 入口 | leanback：`SettingActivity` 增加"儿童模式"项；`HomeActivity` 启动时校验 |
| 文案 | `values` / `values-zh-rCN` / `values-zh-rTW` 同步 |

### 注意

- 无痕模式（`Setting.isIncognito()`）与儿童模式会互相影响记录，需明确优先级。
- 倒计时/锁定要考虑播放器后台播放与 `PlaybackService` 存活。
- 家长密码**不要明文**，存 `Prefers` 前做哈希（项目 mobile 端已有 `androidx.biometric` 可复用）。

## 3. 功能二：内容观看管控（分级 / 白黑名单）

**目标**：按分级隐藏站点或内容，儿童模式只显示白名单。

### 建议落点

| 层 | 改动 |
| --- | --- |
| 数据模型 | `bean/Site.java` 增加字段（如 `rating`、`kidAllowed`）；同步 `gson/` 的解析适配与 `db/SiteDao` |
| 配置来源 | `api/VodConfig.java` 解析 `sites[]` 时读取新字段；`api/BaseConfig` 若需顶层开关一并加 |
| 过滤逻辑 | 新建 `kid/KidFilter.java`：输入 `List<Site>` / `List<Vod>`，输出过滤后列表 |
| UI 接入 | leanback：`SiteAdapter` / `SiteDialog` / `VodPresenter`；mobile 对应适配器。过滤发生在**数据交给 Adapter 之前** |
| 详情/播放 | 若需拦截单集，在 `VideoActivity` 进入前用 `KidGuard.checkAllow(...)` |

### 注意

- `bean` 的字段改动会影响 Gson 反序列化与 Room 列，务必同步 `gson/` 适配与数据库 migration。
- 隐藏不等于安全：若内容来自外部 Spider，App 侧只能按站点/分类维度控制。

## 4. 功能三：家庭 KTV

**目标**：支持歌曲媒体（本地/局域网/配置源）播放 + 歌词显示 + 人声输入混音/音效。

### 建议落点

| 层 | 改动 |
| --- | --- |
| 页面 | 新增 `KtvActivity`：`leanback/ui/activity/KtvActivity.java` + `mobile/...`，各自 layout 与 Manifest 注册 |
| 播放 | 复用 `player/PlayerManager` 与 `ExoPlayerEngine`（KTV 多为音频+歌词，可接受视频轨）。**不要新建引擎** |
| 音效 | `player` 包已有 `AudioEqualizerController`、`ExoAudioEffectController`、`PlayerEffectManager`、`AudioLimiter`、`AudioLoudnessNormalizer`、`AudioStabilizer`、`AudioEffectPreset`。混响/变调可在此基础上扩展，复用 `PlayerEffect` 体系 |
| 歌词 | 优先复用 `bean/Sub`（字幕模型）与 `ExoSubtitleController` 的解析/时间轴能力；若需 LRC 逐字高亮，新增 `bean/Lyric` 与解析器放 `api/` |
| 录音/人声 | 需 `RECORD_AUDIO` 权限，项目已集成 `PermissionX`（`permissionx 1.8.1`），照现有申请模式写；TV 端需确认设备有麦克风输入（遥控器/USB） |
| 曲库 | 走本地文件（`FileActivity` 已有）或新增配置源；若接入 Spider，按 `03` 规范实现 `categoryContent`/`playerContent` |

### 风险（务必先验证）

- **Android TV 音频输入**：多数电视盒子无默认录音输入，KTV 人声混音在 leanback 端可能不可行，需真机验证，否则降级为"仅伴唱播放 + 歌词"。
- **音频延迟**：蓝牙/USB 麦克风延迟明显，需评估回声与音画同步。
- **不要动 `lib-*.aar` 播放器内核**：音效扩展应走 `PlayerEffect` 接口层，避免与上游定制 media3 冲突。

## 5. 界面优化通用约定

- 共用组件/基类在 `app/src/main/res/layout` 与 `main/java/.../ui/`；端侧布局在各自 `res/layout`（三端合计 192 个布局）。
- 主题：`Setting.getThemeColor()` / `getWallColor()` / `getDynamicColor()` 已存在，改配色走这里，不要硬编码。
- leanback 端有 `AndroidAutoSize`（屏幕适配）与 `CustomSelector`（焦点选中态）等自定义控件，改样式优先复用。
- 图片加载统一 Glide（`bundles.glide`，含 avif 与 okhttp3 集成）。

---

## 6. 禁区清单（不要做）

1. ❌ 不要升级/替换 `lib-*.aar` 播放器内核，也不要调整 `proguard-rules-media.pro` 的 keep 规则（会导致 native 类被裁掉）。
2. ❌ 不要把 `forcetech / jianpian / thunder / tvbus / zlive / hook` 加入 `settings.gradle` 构建（上游刻意以 AAR 方式引用）。
3. ❌ 不要在 `build.gradle` 写死依赖版本号。
4. ❌ 不要提交 `local.properties`、`*.jks`、`lib-*.aar`、`/Release`。
5. ❌ 不要改 Room 结构而不写 migration。
6. ❌ 不要在 `main` 的 `AndroidManifest.xml` 注册端侧页面。
7. ❌ 本地 HTTP API 不要加公网暴露能力（官方明确：无鉴权，限局域网）。
