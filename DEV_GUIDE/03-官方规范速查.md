## 1. Spider（内容爬虫）介接

### 1.1 站点最小配置

```json
{
  "key": "demo",
  "name": "Demo",
  "type": 3,
  "api": "./demo.js",
  "ext": {}
}
```

### 1.2 三种语言加载方式

| 语言 | `api` 写法 | 约定 |
| --- | --- | --- |
| Java (JAR) | `csp_Demo` | 类必须在 `com.github.catvod.spider.Demo`，继承抽象 `Spider`；主配置需提供 `spider` 或站点 `jar` |
| Python | `./demo.py` | 相对路径以配置文件位置为基准；导出 `Spider` 类，继承 `base.spider.Spider` |
| JavaScript (QuickJS) | `./demo.js` | ES module 默认导出对象（或构造对象的函数） |
| Node.js | `index.js.md5` 作为入口 | 独立契约：同目录需 `index.js`、`index.config.js`、`index.config.js.md5`；映射为 `node:` 路由，非 QuickJS 的 `export default` 模式 |

对应代码入口：`app/src/main/java/com/fongmi/android/tv/api/` 下的 `JarLoader` / `PyLoader` / `JsLoader`。

### 1.3 方法对照表

| Java / Python | QuickJS | 调用时机 | 返回 |
| --- | --- | --- | --- |
| `init(Context, extend)` / `init(extend)` | `init(ext)` | 建立实例 | — |
| `homeContent(boolean filter)` | `home(filter)` | 进入首页 | `class` 分类 |
| `categoryContent(tid, pg, filter, extend)` | `category(tid, pg, filter, extend)` | 分类/换页/筛选 | `list` + `pagecount` |
| `detailContent(List<String> ids)` | `detail(id)` | 点击卡片 | `list[0]` |
| `searchContent(...)` | — | 搜索 | `list` + `pagecount` |
| `playerContent(flag, id, vipFlags)` | `play(flag, id, vipFlags)` | 选择集数 | `url` 等播放信息 |
| `proxy` / `localProxy` | `proxy` | 本地代理请求 | 数组或 HTTP 响应 |
| `destroy` | `destroy` | 重载/清理 | — |

### 1.4 Result 字段（22 个，对应 `bean/Result.java`）

| 字段 | 类型 | 用途 | 默认 |
| --- | --- | --- | --- |
| `class` | Class[] | 首页分类清单 | `[]` |
| `list` | Vod[] | 首页/分类/搜索卡片；详情取 `list[0]` | `[]` |
| `filters` | object | 以分类 ID 为键，值为 Filter 数组 | `{}` |
| `url` | string / string[] / Url | 播放地址或多画质清单 | — |
| `header` | object / string | 播放请求头；空时回退 Site.header | `{}` |
| `msg` | string | 提示文字（仅 `code=0` 显示） | 空 |
| `code` | integer | 消息控制值（非 HTTP 状态） | 0 |
| `danmaku` | Danmaku[] / string | 弹幕清单或地址 | `[]` |
| `subs` | Sub[] | 外挂字幕清单 | `[]` |
| `playUrl` | string | 解析前缀 | 空 |
| `artwork` | string | 播放页图片 | 空 |
| `jxFrom` | string | 扩展 JSON 解析回报表名 | 空 |
| `flag` | string | 播放分组与解析比对旗标 | App 补入 |
| `desc` | string | 播放页描述 | 空 |
| `format` | string | 媒体 MIME type | — |
| `click` | string | WebView 执行 JS | 空 |
| `key` | string | Site key（被覆写） | App 补入 |
| `position` | integer | 播放起点（毫秒） | — |
| `pagecount` | integer | 总页数 | 0 |
| `parse` | integer | 1 要求解析；0 仍可能触发 | 0 |
| `jx` | integer | 1 要求进入解析 | 0 |
| `drm` | Drm | DRM 设定 | — |

### 1.5 集数格式

- `$$$` 分隔**播放分组**
- `#` 分隔**同组集数**
- `$` 分隔**集数名称与 id**

```json
{
  "vod_play_from": "主線路$$$備用線路",
  "vod_play_url": "第 01 集$demo://ep/1#第 02 集$demo://ep/2$$$第 01 集$backup://ep/1"
}
```

### 1.6 proxy 返回格式

```json
[200, "text/plain; charset=utf-8", "demo response", { "Cache-Control": "no-cache" }]
```

Java 第三格必须是 `InputStream`；Python 可为 `bytes`；Node 直接转接 HTTP 响应。

## 2. 配置字典

### 2.1 点播配置 `vod.json`

```json
{
  "spider": "./spider.jar",
  "sites": [
    { "key": "java_demo", "name": "Java Demo", "type": 3, "api": "csp_Demo" },
    { "key": "js_demo", "name": "JavaScript Demo", "type": 3, "api": "./demo.js", "ext": { "region": "tw" } },
    { "key": "py_demo", "name": "Python Demo", "type": 3, "api": "./demo.py" }
  ],
  "parses": [
    { "name": "JSON 解析範例", "type": 1, "url": "https://example.com/parse?url=",
      "ext": { "flag": ["demo"], "header": { "User-Agent": "ExampleClient/1.0" } } }
  ]
}
```

### 2.2 `sites[]` 字段（19 个）

| 字段 | 类型 | 说明 | 默认 |
| --- | --- | --- | --- |
| `key`* | string | 站点唯一标识，不可重复 | — |
| `name`* | string | 显示名称 | — |
| `type` | integer | 0=XML HTTP、1=JSON HTTP、3=Spider(JAR/JS/PY)、4=HTTP 扩展 JSON | 0 |
| `api`* | string | HTTP 端点 / `csp_` 类 / `./` 相对路径 / 完整网址 | — |
| `ext` | string\|object\|array | type 3 传给 `Spider.init`；HTTP 站点以 `extend` 传送 | — |
| `jar` | string | 覆写全局 spider 的 JAR 位置 | — |
| `click` | string | WebView 执行的 JS | — |
| `playUrl` | string | type 0/1 解析前缀，支持 `json:` 端点或 `parse:` 解析器名 | — |
| `hide` | integer | 1 隐藏站点 | 0 |
| `indexs` | integer | 1 作为索引站点 | 0 |
| `timeout` | integer | 播放超时秒数，最小 1 | 15 |
| `searchable` | integer | 0 停用 / 1 启用（运行期可能为 2） | 1 |
| `changeable` | integer | 0 禁止切换 / 1 可切换 | 1 |
| `lang` | string | 搜索关键字语系转换 | — |
| `danmaku` | integer | 0 停用全局弹幕 API 自动搜索（不影响 Spider 自带弹幕） | 1 |
| `quickSearch` | integer | 0 跳过快速搜索 / 1 启用 | 1 |
| `categories` | string[] | 只保留匹配分类并排序；无匹配则保留原分类 | — |
| `header` | object | HTTP 请求头；`Result.header` 全空时作为默认 | — |
| `style` | Style | 站点卡片样式 | — |

> 注意：官方文档**没有** `filterable` 字段，筛选相关用 `categories` / `searchable` / `changeable` / `hide`。

### 2.3 Parse.type

| 值 | 含义 |
| --- | --- |
| 0 | WebView |
| 1 | JSON API |
| 2 | JAR JSON |
| 3 | JAR 混合 |
| 4 | 并行尝试（优先匹配 `ext.flag`） |

### 2.4 VodConfig 顶层字段（18 个）

`urls`(Depot[])、`msg`、`spider`、`wallpaper`、`logo`、`notice`、`sites`*、`parses`、`lives`、`doh`、`proxy`、`rules`、`headers`、`hosts`、`flags`、`ads`、`danmaku`、`assrt`。

> 只有 `headers`、`proxy`、`rules`、`doh` 经过 `fetchArray`，支持对象数组、外部位置或两者混用。

### 2.5 直播配置

```json
{
  "lives": [{
    "name": "M3U 範例", "url": "./live.m3u", "epg": "https://example.com/epg.xml",
    "logo": "https://example.com/logo/{id}.png", "ua": "ExampleClient/1.0",
    "timeZone": "Asia/Taipei", "boot": false
  }]
}
```

`lives[]` 字段（20 个）：`name`*、`url`、`api`、`ext`、`jar`、`click`、`logo`、`epg`、`ua`、`origin`、`referer`、`timeZone`、`keep`、`timeout`、`header`、`catchup`、`core`、`groups`、`boot`、`pass`。

`Group`：`name`*、`pass`、`channel`*。`Channel`（17 个）：`name`*、`urls`*（可用 `$线路名`）、`number`、`logo`、`epg`、`ua`、`click`、`format`、`origin`、`referer`、`tvgId`、`tvgName`、`header`、`drm`、`parse`、`catchup`。

直播源格式支持 **M3U / TXT / JSON**（JSON 最外层为 Group 数组）。

### 2.6 网络与规则对象

```json
{
  "doh":    [{ "name": "Example DoH", "url": "https://dns.example.com/dns-query", "ips": ["203.0.113.53"] }],
  "proxy":  [{ "name": "本機代理", "hosts": ["media.example.com"],
               "urls": ["http://127.0.0.1:8080", "socks5://127.0.0.1:1080"] }],
  "hosts":  ["media.example.com=203.0.113.10"],
  "ads":    ["ads.example.com"]
}
```

`Rule`：`name`、`hosts`、`regex`、`click`（CSS 选择器数组）、`script`、`exclude`。
`Header`：`host`、`header`（注入/覆写的请求头）。

## 3. 本地 HTTP API（`server` 包）

- **端口**：9978 起依次尝试至 9998，取首个成功启动者；以 App 显示地址为准。
- **鉴权**：无 token 校验，**仅限可信局域网**，勿暴露公网。
- **响应**：多数为 `text/plain`（即使内容是 JSON）。
- 参数中文/URL/JSON 需 URL 编码。

### 3.1 `/action` 的 `do` 取值

| do | 参数 | 用途 |
| --- | --- | --- |
| `control` | `type` | 播放控制 |
| `danmaku` | `text` | 发送即时弹幕 |
| `refresh` | `type`（+`path`/`json`） | 刷新页面 / 推送字幕、弹幕、Vod |
| `push` | `url` | 推送播放 |
| `file` | `path` | 打开设备文件（非上传） |
| `search` | `word` | 搜索 |
| `setting` | `text`、`name` | 导入配置 |
| `cast` | `config`、`device`、`history` | 投放 |
| `sync` | `type`、`mode`、`force`、`device`、`config`、`targets`、`configs` | 同步记录/收藏 |

`control` 的 `type`：`play` `pause` `stop` `prev` `next` `repeat` `replay`
`refresh` 的 `type`：`live` `detail` `player` `category` `subtitle`(需 path) `danmaku`(需 path) `vod`(需 json)
`sync` 的 `type`：`history`（记录）/ `keep`（收藏）；`mode`：0=收发（默认）/ 1=只收 / 2=只发

> `OK` 不代表动作已完成 —— `/action` 通常先派发事件再返回 `OK`。

### 3.2 其他端点

| 端点 | 方法 | 说明 |
| --- | --- | --- |
| `/media` | GET | 播放状态 8 字段：`state` `speed` `duration` `position` `url` `title` `artist` `artwork`；无播放时返回 `{}` |
| `/device` | GET | 设备信息：`uuid` `name` `ip` `type` `serial` `eth` `wlan` `time` |
| `/file/{path}` | GET | 浏览目录 / 下载文件（支持 Range） |
| `/upload` | POST multipart | `path` 必填且目录须存在 |
| `/newFolder` `/delFolder` `/delFile` | GET/POST | 目录管理（删除为递归） |
| `/cache` | GET/POST | `do=get/set/del`、`key`、`value`、`rule`（命名空间） |
| `/proxy` | GET/POST | 合并参数交 `BaseLoader.proxy` |
| `/parse` | GET | `jxs`（解析前缀）+ `url`，返回 `text/html` |
| `/image/{key}` | GET | 已缓存图片，未命中 404 |
| `/tvbus` | GET | 直播 Core 的 RESP 字串 |
| `/` | GET | 内置 index.html 控制页 |

## 4. App 功能清单（`features`）

- **界面**：电视版（遥控器 + 大屏）、手机版（触控 + 直向/横向），共用核心能力。
- **浏览搜索**：依配置建立分类与筛选、跨站点并行搜索、快速搜索、换页。
- **播放**：硬解/软解切换、倍速、画面比例、手机版画中画、背景音频、片头片尾跳过。
- **字幕弹幕**：外挂 SRT/SSA/ASS、系统字幕样式、时间轴同步弹幕、局域网即时推送。
- **直播**：M3U/TXT/JSON 源、分组选台、备用线路、EPG（XMLTV）、直播收藏、追看/时移（依源支持）。
- **个人**：观看记录与进度恢复、收藏管理、无痕模式。
- **互联**：DLNA 投放与接收（电视端作 Renderer）、Android Auto（车机浏览记录与直播分组，播放/暂停/上下/停止）、局域网 HTTP 远端控制与同步。
- **网络工具箱**：DoH、Proxy、Hosts、请求头、WebView Rules。

## 5. 免责与约束（官方强调）

- **App 本身不内置或提供任何内容来源**，内容需自行配置。
- 本地 HTTP API 无鉴权，仅限可信局域网，不要转发到公网。
- 实际能力依配置、媒体、播放引擎与设备而异。
